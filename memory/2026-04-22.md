## 🐛 Research Pipeline Bug Identified

**VCResearchStrategy.ts Issue:** The research phase writes request files to `/tmp/vc-research-{name}-request.json` but **no sub-agent was spawned to process them**. Pipeline fell back to mock data instead of executing real web research.

**Correct Pattern:**
1. Script writes request file
2. Post to Discord #annotations OR spawn sub-agent
3. Sub-agent executes web_search/web_fetch tools
4. Save results to `/tmp/vc-research-{name}-result.json`
5. Script reads cache, updates Notion

**Workaround:** Manual deep research using web_search + web_fetch + LinkedIn discovery (what I did for Wave 5)
