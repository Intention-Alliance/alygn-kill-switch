## 🏗️ Key Architectural Decisions

### 1. Hybrid Script + Sub-Agent Architecture

**Decision:** Use hybrid approach (not pure sub-agents for everything)

| Script                 | Type           | Tools                      | Agent ID Pattern                        |
| ---------------------- | -------------- | -------------------------- | --------------------------------------- |
| `checkpoint.js`        | Pure script    | Deterministic I/O          | N/A                                     |
| `x-warmup-tracker.js`  | Hybrid         | Grok (X search) + Supabase | `warmth-analyst:{region}:{wave}`        |
| `muni-compliance.js`   | Hybrid         | Perplexity + Firecrawl     | `compliance-checker:{region}:{wave}`    |
| `reply-tracker.js`     | Hybrid         | IMAP + LLM classification  | `reply-classifier:{region}:{wave}`      |
| `campaign-approval.js` | Pure sub-agent | Perplexity + Firecrawl     | `campaign-personalizer:{region}:{wave}` |
| `weekly-report.js`     | Pure sub-agent | Perplexity + Supabase      | `analyst:{region}:{wave}`               |

**Why hybrid:**

- Deterministic tasks (I/O, calculations) → Scripts (faster, no hallucination)
- Contextual tasks (tone, personalization, research) → Sub-agents (LLM reasoning)
- Agent IDs include region:wave for modularity and tracking

### 2. Web Intelligence Fallback Chain

**Updated:** `scripts/utils/web-intelligence.js`

**Search fallback:**

1. Perplexity Sonar Pro (via OpenRouter) → Primary
2. OpenClaw `web_search` (Brave API) → Fallback

**Scrape fallback:**

1. Firecrawl API → Primary
2. OpenClaw `web_fetch` → Fallback

**NEW:** URL variants (www/non-www)

- Automatically tries both `https://example.com` and `https://www.example.com`
- Returns `requestedUrl` vs `actualUrl` in metadata
- Applied to both Firecrawl and web_fetch

---

### 3. Grok for X/Twitter Activity (NOT web search)

**Critical insight:** X/Twitter is private - web search won't find activity

**Correct tool mapping:**

- **Grok API** → X/Twitter search (`from:@handle since:2026-02-01`)
- **Perplexity** → General web research (municipalities, governance, news)
- **Firecrawl** → Web scraping (official websites, articles)

**Why:** X content is behind auth wall. Grok has native X access.

## 🔧 System Improvements

### Web Scraping Fix

- **Problem:** Some sites only work with www or non-www
- **Solution:** `generateUrlVariants()` function tries both automatically
- **Benefit:** Higher success rate, no manual retry needed

### Agent ID Pattern

- **Pattern:** `{agent-type}:{region}:{wave}`
- **Examples:** `warmth-analyst:cr:1`, `compliance-checker:usa:2`
- **Benefit:** Modular tracking per region/wave, easier debugging

### Current Date Context

- **Hardcoded:** "March 4, 2026" in all sub-agent prompts
- **Rule:** Use ONLY 2025-2026 data
- **Benefit:** Prevents outdated research/hallucinations

## 💡 Lessons Learned

1. **Grok ≠ Web search** - Grok is for X/Twitter specifically. Use Perplexity for general web research.
2. **Hybrid > Pure sub-agents** - Deterministic tasks should stay in scripts (faster, no hallucination risk)
3. **URL variants matter** - Many municipal sites redirect www↔non-www differently
4. **Agent ID modularity** - Region:wave pattern enables parallel execution and easier debugging
5. **Tania's control** - She needs approval step before posting (not fully automated)
