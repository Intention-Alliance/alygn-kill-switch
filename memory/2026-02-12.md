2. **Extract existing Conversation Logs** using regex pattern

**Result:**
- Summary section: Replaced every time (fresh data)
- Conversation Logs section: Preserved (manual entries safe)
- No duplication

### Code Changes

```javascript
// Step 1: Read existing page
const existingPage = await notionRequest('GET', `/v1/pages/${pageId}`);
const existingNotes = existingPage.properties?.Notes?.rich_text?.[0]?.text?.content || '';
```

```javascript
async function deepResearchVC(vc) {
  // 1. Check cache
  if (fs.existsSync(researchFile)) {
    return JSON.parse(fs.readFileSync(researchFile));
  }

  // 2. Send research request to Wobblus via sessions_send
  const prompt = `Research ${vc.name}. Execute web_fetch + web_search. Save JSON to ${researchFile}`;
  await execAsync(`echo '${prompt}' | openclaw sessions send --session-key=... --timeout-seconds=120`);

  // 3. Wait for Wobblus to save research file (up to 10 attempts, 2s each)
  let attempts = 0;
  while (!fs.existsSync(researchFile) && attempts < 10) {

}
```
