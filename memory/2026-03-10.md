## 🐛 Issues Discovered

### X API Rate Limiting
- **Reply limits:** Some replies failed with 403 Forbidden (rate limiting)
- **Pattern:** ~2-3 replies allowed before hitting limit
- **Mitigation:** 25-40s delays between threads, 3-5s before replies

### Prompt #13 Missing from Notion
- **Issue:** Prompt was deleted during update, not modified
- **Resolution:** Recreated with XML format instructions
- **Parsing bug:** Multi-line content broke regex - fixed by simplifying extraction

### Notion API Smart Quotes
- **Issue:** Prompt #13 used Unicode smart quotes (`'`) instead of ASCII (`'`)
- **Impact:** Regex `['"]` didn't match smart quotes
- **Fix:** Updated regex to support both ASCII and Unicode quotes
