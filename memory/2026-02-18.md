## Architecture Principles (Learned 2026-02-11)

### Browser vs X API Separation
- ❌ **Browser is NOT for posting** - ONLY for exploring/navigating
- ✅ **Browser role:** Navigate /explore → Extract posts → workflow.json
- ✅ **X API role:** Read workflow.json → Apply format → Post via X API
- **Why:** Browser for natural content discovery, X API for reliable programmatic posting

### Correct Workflow
1. Browser discovery (explore/navigate)
2. Decision engine (Grok evaluation)
3. workflow.json created (raw content)
4. x-api-executor reads workflow → applies format → posts
