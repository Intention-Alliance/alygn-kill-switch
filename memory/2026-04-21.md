## Critical Bug Fix: Municipal Cron Jobs Using Wrong `--type` Flag

**Time:** 2026-04-21 00:18 CST
**Status:** FIXED ✅

### Root Cause
All 3 municipal cron jobs used `--type=muni` instead of `--type=municipal`.

The CLI (`bin/alygn-outreach.ts`) only accepts `vc` or `municipal` (exact match). When `--type=muni` was passed, it fell back to default `vc`, generating **English** emails instead of Spanish TRAIGA Act templates.

### Evidence
- `alygn-muni-afternoon`: `--type=muni` → English content
- `alygn-muni-morning`: `--type=muni` → English content  
- `alygn-muni-evening`: `--type=muni` → English content

### Fix Applied
Replaced `--type=muni` with `--type=municipal` in all 3 cron jobs.

### Verification
After fix: All jobs now use `--type=municipal` (exact match confirmed via grep).
