## 🔍 X/TWITTER DISCOVERY METHODOLOGY (CRITICAL)

### **Problem Identified:**
- Assumed naming pattern `Muni[municipality]` failed (e.g., `MuniEscazu` is NOT the official account)
- `MEscazu` is the actual handle for Escazú municipality
- Fake/inactive accounts have: no profile pic, no posts, no followers, no activity

### **Correct Methodology:**

#### **Step 1: Hashtag-First Search (NOT handle guessing)**
```
DON'T: Search for "@MuniEscazu" directly
DO: Search for "#MuniEscazu" or "#Escazú" hashtag
```

**Why:** Hashtags show real posts from real accounts about the municipality.

#### **Step 2: Review 3-10 Profiles from Hashtag Posts**
```
For each post with the hashtag:
1. Click on the profile who posted
2. Check if it's official municipality account
3. Compare across multiple posts
```

**Why:** Multiple posts = cross-verification of official account.

#### **Step 3: Legitimacy Verification Checklist**
```
✅ OFFICIAL ACCOUNT SIGNALS:
- Profile photo (municipal logo/scudo)
- Verified badge (if available)
- Bio mentions "Municipalidad de [canton]"
- Posts are institutional (official announcements, municipal news)
- Regular posting activity (not dormant)
- Followers/engagement (real people interacting)
- Links to official website ([canton].go.cr)

❌ FAKE/INACTIVE SIGNALS:
- No profile photo
- No posts or very few
- No followers/following
- No engagement (likes, retweets)
- Generic bio or empty
- Personal content (not institutional)
```

#### **Step 4: Common Sense Validation**
```
Ask: "Would the municipality post this?"
- Institutional announcements ✅
- Municipal services info ✅
- Local events (official) ✅
- Personal opinions ❌
- Political campaign content ❌ (unless official campaign account)
- Unrelated content ❌
```

#### **Step 5: Cross-Reference with Known Data**
```
If you have confirmed data:
- Mayor name matches bio/posts
- Recent initiatives mentioned in posts
- Location matches municipality
- Website link matches official domain
```

### **Search Strategy by Priority:**

**Tier 1 (Most Reliable):**
1. Hashtag search: `#[MunicipalityName]` (e.g., `#Escazú`, `#Curridabat`)
2. Hashtag + keyword: `#[Municipality] municipalidad`, `#[Municipality] alcalde`
3. Check profiles of top 3-10 posts

**Tier 2 (Backup):**
1. Google search: `[Municipality] Costa Rica Twitter account`
2. Official website: Check footer/social media links
3. Mayor's name + Twitter: `[Alcalde Nombre] Twitter`

**Tier 3 (Last Resort):**
1. Handle pattern guessing: `Muni[municipality]`, `Mun[municipality]`, `[municipality]CR`
2. Verify each guess with legitimacy checklist

### **Time Allocation:**
- Hashtag search: 2-3 min per municipality
- Profile review (3-10 accounts): 5-7 min per municipality
- Verification: 2-3 min per municipality
- **Total: ~10-15 min per municipality**

### **Example Workflow (Escazú):**

```
1. Search: "#MuniEscazu" OR "#Escazú"
2. Found posts from:
   - @MEscazu (10 posts, municipal logo, bio: "Municipalidad de Escazú")
   - @MuniEscazu (0 posts, no photo, empty bio) ← FAKE
   - @EscazuNews (50 posts, news site, NOT official) ← NOT OFFICIAL
3. Verify @MEscazu:
   - ✅ Profile photo: Municipal escudo
   - ✅ Bio: "Municipalidad de Escazú - Sitio oficial"
   - ✅ Posts: Institutional announcements, municipal services
   - ✅ Website link: escazu.go.cr
   - ✅ Activity: Regular posts, real engagement
4. Conclusion: @MEscazu is the official account
```
