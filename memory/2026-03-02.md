## ⚠️ Critical Lesson: X Profile Validation

**Problem Discovered:**
- Assumed 4 X handles: @MuniLiberia, @MuniSanJoseCR, @MuniHeredia, @MuniCartago
- **Reality:** Only 1/4 was correct (@CartagoMuni)
- **75% failure rate** - would have engaged with fake profiles

**Solution:**
- Created `x-profile-validator.js` to verify handles BEFORE engagement
- Validation flow: Search → Verify → Check Activity → Recommend Action
- Actions: `direct_engagement`, `mention_only`, `skip`

**Expected Results:**
- Direct engagement: 20-30% (verified & active)
- Mention only: 10-20% (exists but inactive)
- Skip X (email only): 50-70% (no X presence)

**Lesson:** NEVER assume social media handles exist. ALWAYS validate first.

## 🔧 Technical Learnings

### Firecrawl Issues
- Firecrawl API returns 408/500 errors frequently
- **Solution:** Use pre-verified data + web_search instead
- `web_fetch` tool more reliable than direct Firecrawl calls
- Always try with `www.` prefix (some sites require it)

### Website Verification
- `https://muniliberia.go.cr` → ✅ Works (redirects to www)
- `https://msj.go.cr` → ✅ Works
- `https://muni-carta.go.cr` → ❌ 408 Timeout
- `https://www.muni-carta.go.cr` → ✅ Works (needs www.)

**Lesson:** Always try with and without `www.` prefix
