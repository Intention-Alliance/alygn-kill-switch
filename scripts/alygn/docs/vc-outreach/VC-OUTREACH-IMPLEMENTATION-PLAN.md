```javascript
async function discoverVCs(config) {
  // 1. WEB SEARCH PHASE
  const searchResults = await web_search({
    query: config.searchQuery, // e.g., "AI safety seed VCs"
    count: 20,
    country: "US"
  });
  
  const vcCandidates = parseSearchResults(searchResults);
  
  // 2. BROWSER AUTOMATION PHASE
  for (const vc of vcCandidates) {
    // Navigate to VC website
    const vcWebsite = await browser.navigate({
      profile: "alygn",
      targetUrl: vc.url
    });
    
    // Extract team/contact info
    const snapshot = await browser.snapshot({
      profile: "alygn",
      targetId: vcWebsite.targetId
    });
    
    const contacts = extractContactInfo(snapshot);
    
    // LinkedIn partner search
    const linkedInResults = await searchLinkedIn(vc.name);
    
    // Merge data
    const enrichedVC = {
      name: vc.name,
      website: vc.url,
      partners: contacts.partners,
      emails: contacts.emails,
      investmentThesis: contacts.thesis,
      portfolioCompanies: contacts.portfolio,
      relevanceScore: scoreRelevance(contacts)
    };
    
    // 3. SAVE TO NOTION
    if (enrichedVC.relevanceScore > 7) { // Only high-relevance VCs
      await createNotionEntry(enrichedVC);
    }
  }
}
```

**Relevance Scoring Algorithm:**
```javascript
function scoreRelevance(vcData) {
  let score = 0;
  
  // Investment thesis keywords
  const keywords = [
    "ai safety", "alignment", "agi", "governance",
    "existential risk", "coordination", "oversight"
  ];
  
  const thesisText = vcData.investmentThesis.toLowerCase();
  keywords.forEach(keyword => {
    if (thesisText.includes(keyword)) score += 2;
  });
  
  // Portfolio analysis
  const hasAISafetyInvestments = vcData.portfolioCompanies.some(company =>
    company.description.match(/safety|alignment|governance/i)
  );
  if (hasAISafetyInvestments) score += 3;
  
  // Stage alignment (seed/Series A)
  if (vcData.stage.match(/seed|pre-seed|series a/i)) score += 1;
  
  // Geography (US/EU priority)
  if (vcData.location.match(/US|UK|EU|Switzerland/i)) score += 1;
  
  return Math.min(score, 10); // Cap at 10
}
```

## 📬 Phase 5: Outreach Orchestration & Notification System

### 5.1 Email Sending Pipeline

**Script:** `scripts/alygn/vc-outreach/outreach-orchestrator.js`

**Workflow:**
```javascript
async function runOutreachCampaign() {
  // 1. Query Notion for "Pending" VCs
  const pendingVCs = await queryNotionVCs({
    status: "Pending",
    limit: 12, // Batch size per day (1/hour, 12 hours)
    priority: "High" // Start with high-priority VCs
  });
  
  // 2. Generate personalized emails
  const emails = [];
  for (const vc of pendingVCs) {
    const email = await generatePersonalizedEmail(vc);
    emails.push(email);
  }
  
  // 3. Send emails (with rate limiting)
  for (const email of emails) {
    await sendEmail(email);
    await updateNotionStatus(email.metadata.vcId, {
      status: "Contacted",
      contactDate: new Date().toISOString().split('T')[0],
      emailVariant: email.metadata.variant,
      painPoints: email.metadata.painPoints.join("; ")
    });
    
    // Rate limit: 1 email per hour (Gmail SMTP limits, hourly cron)
    // Note: Cron job runs hourly, so only 1 email sent per execution
  }
  
  // 4. Send summary to WhatsApp
  await sendWhatsAppSummary({
    totalSent: emails.length,
    vcsSent: emails.map(e => e.metadata.vcId),
    nextBatch: pendingVCs.length - emails.length
  });
}
```

## 🔐 Security Considerations

### Credentials Management
- **Never hardcode** API keys, SMTP credentials, or OAuth tokens
- Use `$HOME/.openclaw/workspace/config/credentials.json` for all secrets
- Rotate Gmail app password quarterly
- Use read-only Notion tokens where possible

### Email Handling
- **Gmail forwarding:** Tania's personal email → alyygn@gmail.com (isolated test account)
- **Production:** Only move to `outreach@alyygn.com` after validation
- **IMAP access:** Use app-specific password (not main account password)

### Data Privacy
- **PII handling:** VC contact info is sensitive → never log full emails
- **Notion access:** Restrict to Alygn workspace only
- **Browser automation:** Use isolated Chrome profile (alygn)

### Rate Limiting
- **Gmail SMTP:** Max 100 emails/day → batch of 10/day is safe
- **Notion API:** Max 3 requests/second → implement backoff
- **Browser automation:** Human-like delays between actions
