# Daily Reports - Multi-Org Activity Summaries

This directory contains daily summary reports for all working organizations (ALYGN, BitcashOrg, AndlerRL Personal). Generated by daily tracker scripts and consolidated into multi-org briefings.

---

## 📁 Directory Structure

```
daily-reports/
├── audio/              # Audio versions of daily reports (TTS)
├── {YYYY-MM-DD}/       # Date-stamped daily reports
│   ├── alygn-daily-YYYY-MM-DD.md
│   ├── bitcash-daily-YYYY-MM-DD.md
│   ├── personal-daily-YYYY-MM-DD.md
│   └── multi-org-summary-YYYY-MM-DD.md
└── README.md           # This file
```

---

## 🎯 Purpose

**This directory serves as:**

1. **Daily Activity Archive** — Historical record of all org activities
2. **Morning Briefing Source** — Input for 8 AM multi-org briefing
3. **Progress Tracking** — Track daily progress across organizations
4. **Context for Memory** — Source for updating `MEMORY.md` and daily memory files

## 🔧 Report Generation Workflow

### Daily Automation Flow

```
1. 3:30 AM → ALYGN daily tracker runs
   ↓
2. 3:45 AM → BitcashOrg daily tracker runs
   ↓
3. 4:00 AM → Personal daily tracker runs
   ↓
4. 8:00 AM → Multi-org morning briefing consolidates all reports
   ↓
5. 8:00 AM → WhatsApp delivery to Andler
   ↓
6. Optional: Audio version generated (TTS)
```

## 🔊 Audio Reports (`audio/`)

**Purpose:** TTS versions of daily reports for listening

**Generated by:** `sag` CLI (ElevenLabs TTS)  
**Voice:** Wobblus (Antoni + Gnome pitch)  
**Format:** OGG Vorbis (WhatsApp-compatible)

**Files:**

```
audio/
├── alygn-daily-2026-02-10.ogg
├── bitcash-daily-2026-02-10.ogg
└── multi-org-summary-2026-02-10.ogg
```

**Usage:**

```bash
# Generate audio report
sag -v ErXwobaYiN019PkySvjV \
  --speed 1.35 \
  --stability 0 \
  --style 0.9 \
  -i daily-reports/2026-02-10/alygn-daily-2026-02-10.md \
  -o daily-reports/audio/alygn-daily-2026-02-10.ogg
```

## 🚀 Usage Examples

### View Today's Reports

```bash
# View all today's reports
ls -lh daily-reports/$(date +%Y-%m-%d)/

# Read ALYGN report
cat daily-reports/$(date +%Y-%m-%d)/alygn-daily-$(date +%Y-%m-%d).md

# Read multi-org summary
cat daily-reports/$(date +%Y-%m-%d)/multi-org-summary-$(date +%Y-%m-%d).md
```

### Generate Reports Manually

```bash
# Run individual trackers
node scripts/alygn/daily-tracker.js
node scripts/bitcash/daily-tracker.js
node scripts/personal/daily-tracker.js

# Generate multi-org briefing
node scripts/system/morning-briefing.js
```

### Search Across Reports

```bash
# Search for keyword across all reports
grep -r "VC outreach" daily-reports/

# Find all reports mentioning specific project
grep -r "masterbots" daily-reports/2026-02-*/bitcash-*.md

# Count total GitHub commits this week
grep -h "Commits:" daily-reports/2026-02-*/bitcash-*.md | awk '{sum+=$2} END {print sum}'
```

## 📂 File Retention

**Keep:**

- ✅ All daily reports (indefinitely)
- ✅ Audio reports for 30 days

**Archive:**

- Compress reports older than 90 days (gzip)
- Delete audio older than 30 days

**Example retention script:**

```bash
# Compress old reports
find daily-reports/ -name "*.md" -mtime +90 -exec gzip {} \;

# Delete old audio
find daily-reports/audio/ -name "*.ogg" -mtime +30 -delete
```

## 🛠️ Troubleshooting

### "No reports generated today"

**Fix:** Check if daily trackers ran:

```bash
openclaw cron list | grep daily-tracker
openclaw cron runs <jobId>
```

### "Report incomplete or missing data"

**Fix:** Run tracker manually with debug:

```bash
node scripts/alygn/daily-tracker.js --debug
```

### "Audio report not generated"

**Fix:** Check TTS configuration:

```bash
# Test TTS
sag -v ErXwobaYiN019PkySvjV "Test audio" -o test.ogg

# Verify ElevenLabs API key
node scripts/shared/load-credentials.js get elevenlabs.apiKey
```
