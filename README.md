## 🔒 Security Principles

1. **Context Isolation** — Projects stay compartmentalized (Alygn ≠ Bitcash ≠ Personal)
2. **No Hardcoding** — All credentials in `config/credentials.json`
3. **Read-Only Repos** — Never edit cloned repos, only reference them
4. **NDA Compliance** — Strict confidentiality for ALYGN (see SECURITY.md)
5. **Backup Daily** — 2 AM cron backs up critical files
