# @alygn/wizard-tui

Alygn Kill Switch — interactive install wizard (Bun + clack TUI).

Installs the kill-switch system on a fresh machine: system detection,
guided configuration, secret generation, systemd units, first-run
verification, and dashboard handoff. Non-interactive replay via
`--config` for automated installs.

## Requirements

- Linux with systemd (PID 1)
- [bun](https://bun.sh) ≥ 1.3
- redis-server (running on `localhost:6379` by default)
- git (recommended)

## Usage

```bash
# Interactive install
bun run wizard

# Non-interactive replay from a JSON config
bun run wizard --config ./config.json

# Preflight + config validation only (no writes)
bun run wizard --dry-run

# Uninstall (add --purge to also delete .env and data dirs)
bun run wizard uninstall [--purge]
```

### Exit codes

| Code | Meaning        |
|------|----------------|
| 0    | ok             |
| 1    | preflight fail |
| 2    | config invalid |
| 3    | install fail   |
| 4    | verify fail    |

## What it installs

| Unit | Purpose |
|------|---------|
| `alygn-web-regulator.service` | Kill-switch API (bun, port 3000) |
| `alygn-agent-plane.service` | Agent heartbeat + Ollama interceptor |

Env files are written with mode `0600` and secrets are generated by
`apps/server-kill-switch/scripts/security/generate-secrets.sh`
(idempotent — existing keys are never overwritten). The agent's
`ALYGN_AGENT_API_KEY` mirrors the server's `KILL_SWITCH_API_KEY`.

## Bootstrap (Epic 1.5)

```bash
curl -fsSL <release-url>/install.sh | bash
```

The script verifies its own checksum and the release tarball checksum
before extracting to `$INSTALL_DIR` (default `~/alygn`), installs
production dependencies, then execs the wizard.

## Development

```bash
bun install
bun test          # lib tests
bun run type-check
bun run lint
```

Layout: `src/lib/` is pure logic (no clack imports), `src/steps/` is the
clack UI layer. See `docs/specs/wizard-tui-interface-spec.md` for the
shared interface contract.
