### Core Script: `twitter-automation-v2.js`

**What it does:**
1. Fetches prompt template from Notion (by prompt number)
2. Calls Grok API with optional X search (`--search` flag)
3. Saves output to `/twitter-outputs/prompt-{number}-{timestamp}.md`
4. Logs to `/logs/{date}/twitter-automation.md`

**What it DOESN'T do (yet):**
- ❌ Dynamic value injection (`[INSERT REAL DATA]`)
- ❌ Post to X via bird CLI
- ❌ Neuro-marketing analysis
- ❌ Aggregate analytics into Morning Brief

## 🎯 Enhancement Plan (Build ON TOP, Don't Replace)

### Phase 1: Dynamic Value Injection (Priority)

**Goal:** Replace `[placeholder]` values in prompts with REAL data before sending to Grok.

**How:**
1. Modify `twitter-automation-v2.js` to:
   - Load latest trend data from previous prompt #13 outputs
   - Load analytics from previous prompt #17 outputs
   - Inject real values before Grok call

**Example:**
```javascript
// Before: Generic prompt from Notion
"Analyze this X analytics data: [insert data like follower growth, impressions, top posts]"

// After: Dynamic injection
"Analyze this X analytics data: Followers gained: 45, Impressions: 12800, Top post: 320 likes"
```

**Files to modify:**
- `scripts/alygn/twitter-automation-v2.js` — Add injection logic
- Create `scripts/alygn/lib/data-aggregator.js` — Load & aggregate trend/analytics data

---

### Phase 2: Bird CLI Integration (Posting)

**Goal:** Actually POST generated content to **@aialyygn** (staging) via `bird` CLI.

**Workflow:**
1. Content generated by cron jobs → saved to `/twitter-outputs/`
2. New script: `twitter-poster.js` reads approved content
3. Posts via `bird tweet "content"` or `bird reply <id> "content"`

**Safety gates:**
- Content marked as `READY_FOR_REVIEW` until approved
- Manual approval workflow OR auto-post with quality threshold
- Rate limiting (max 10 posts/day)

**New files:**
- `scripts/alygn/twitter-poster.js` — Post approved content
- `scripts/alygn/lib/approval-queue.js` — Track approval status

---

### Phase 3: Neuro-Marketing Analytics Layer

**Goal:** Add psychological analysis to the daily analytics report.

**What to add:**
1. Parse prompt #17 outputs for engagement metrics
2. Analyze WHY top posts worked (curiosity gap, status signaling, etc.)
3. Generate "Morning Brief" with actionable insights

**New files:**
- `scripts/alygn/morning-brief-generator.js` — Aggregate + analyze
- `scripts/alygn/lib/neuro-analyzer.js` — Psychological signal detection

**Cron job update:**
- Add new job at 5 PM to generate Morning Brief from prompt #17 output

### Phase 4: Browser-Based Trend Discovery (Optional)

**Goal:** Use browser snapshots to find additional trends beyond Grok search.

**When to implement:** After Phases 1-3 are stable.
