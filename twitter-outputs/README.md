# Twitter Outputs - Content & Engagement Tracking

This directory contains X/Twitter outputs generated for posting and engagement tracking. All generated content, workflow files, and media assets are organized by project context.

---

## 📁 Directory Structure

```
twitter-outputs/
├── alygn/              # ALYGN Twitter content
│   ├── workflow-*.json # Workflow orchestration files
│   ├── *.png           # Generated media assets
│   └── *.md            # Content drafts
├── bitcashorg/         # BitcashOrg Twitter content
└── personal/           # Personal Twitter content
```

---

## 🎯 Purpose

**This directory serves as:**

1. **Content Archive** — Historical record of all generated Twitter content
2. **Engagement Tracker** — Track posts, replies, follows, and engagement metrics
3. **Media Library** — Store generated images and media assets
4. **Workflow Coordination** — Orchestrate multi-step Twitter automation

---

## 📋 File Types

### Workflow Files (`workflow-*.json`)

**Purpose:** Orchestration files for Twitter automation workflows

**Structure:**

```json
{
  "timestamp": 1770484855297,
  "posts": [
    {
      "type": "thread",
      "content": ["Hook", "Point 1", "Point 2", "..."],
      "imagePath": "path/to/image.png",
      "status": "posted" | "pending"
    }
  ],
  "replies": [
    {
      "targetUser": "@username",
      "tweetId": "1234567890",
      "replyText": "...",
      "status": "posted" | "pending"
    }
  ],
  "profiles": [
    {
      "handle": "@username",
      "reason": "Relevant profile",
      "followStatus": "followed" | "pending"
    }
  ]
}
```

**Generated by:** `scripts/alygn/x-twitter/twitter-automation-v2.js`  
**Used by:** `scripts/alygn/x-twitter/post-via-x-api.js`, engagement scripts

---

### Media Assets (`*.png`, `*.jpg`)

**Purpose:** Generated images for Twitter posts

**Naming convention:** `{topic-slug}.png`

**Examples:**

- `ai-oversight-crisis.png`
- `reward-hacking.png`
- `inner-misalignment.png`

**Generated by:** `scripts/alygn/x-twitter/generate-images-selective.js`  
**Used in:** Twitter posts via X API or browser automation

---

### Content Drafts (`*.md`)

**Purpose:** Human-readable drafts and ready-to-post guides

**Examples:**

- `PHASE2-READY-TO-POST.md` — Copy/paste guide for manual posting
- `twitter-content-draft.md` — Generated content for review

## 🔧 ALYGN Twitter Workflow

### Content Generation Flow

```
1. Generate content → scripts/alygn/x-twitter/twitter-automation-v2.js
   ↓
2. Create workflow JSON → twitter-outputs/alygn/workflow-{timestamp}.json
   ↓
3. Generate images → scripts/alygn/x-twitter/generate-images-selective.js
   ↓
4. Post via X API → scripts/alygn/x-twitter/post-via-x-api.js
   ↓
5. Engagement → scripts/alygn/x-twitter/engagement-system.js
```

## 🚀 Usage Examples

### Generate Content & Workflow

```bash
# Run content generation
node scripts/alygn/x-twitter/twitter-automation-v2.js

# Outputs workflow JSON to:
# twitter-outputs/alygn/workflow-{timestamp}.json
```

### Generate Images for Workflow

```bash
# Selective image generation
node scripts/alygn/x-twitter/generate-images-selective.js

# Outputs images to:
# twitter-outputs/alygn/{topic-slug}.png
```

### Post via X API

```bash
# Post workflow content
node scripts/alygn/x-twitter/post-via-x-api.js twitter-outputs/alygn/workflow-*.json

# Updates workflow JSON with:
# - status: "posted"
# - tweetIds: ["123", "456", ...]
```

### Manual Posting Guide

```bash
# For workflows that need manual posting:
cat twitter-outputs/alygn/PHASE2-READY-TO-POST.md

# Copy/paste content from the guide
# Manually attach images from twitter-outputs/alygn/
```

## 🛠️ Troubleshooting

### "Workflow file not found"

**Fix:** Ensure you're pointing to the correct workflow file:

```bash
ls -lt twitter-outputs/alygn/workflow-*.json | head -5
node scripts/alygn/x-twitter/post-via-x-api.js twitter-outputs/alygn/workflow-{latest}.json
```

### "Image path not found in workflow"

**Fix:** Generate images first:

```bash
node scripts/alygn/x-twitter/generate-images-selective.js
# Then run posting script
node scripts/alygn/x-twitter/post-via-x-api.js twitter-outputs/alygn/workflow-*.json
```

### "X API rate limit exceeded"

**Fix:** Wait 15 minutes or use browser automation fallback:

```bash
node scripts/alygn/x-twitter/twitter-browser-automation-v4.js
```
